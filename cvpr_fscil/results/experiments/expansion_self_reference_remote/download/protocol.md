# Own-reference paired certification, frozen-readout study

Frozen scope: CIFAR-100, Pets, ImageNet-R; CLIP L/14 and B/32; ten partitions, two orders, five arrivals, 5-shot supports, 3636-setting independent base-only selection, cap40 calibration. Compare retained_query/none/fixed and dense_query/none/fixed using both original common reference and each fixed readout's own closed-base winner. Same candidate offsets, paired test, r=.95, delta=.05/5. The within-base winner is invariant across arrivals for these readouts; assert this from predictions. Self-reference changes the accuracy contract, so report absolute base accuracy and closed-base targets alongside retention. This stage does not substitute an expanded-vocabulary HyCal base winner for its true closed-vocabulary predictor; HyCal own-reference requires its original closed-vocabulary score computation. No Dense-to-Ridge redesign in this stage.

Archive reuse is explicit. Input hashes, every path/session, exact offsets and p-values are retained. Write one atomic checkpoint per partition/order/session. Final contrasts average orders within partitions and use paired bootstrap intervals. Never choose methods or constants from test results.
